# PseudoHat

Клиентский Fabric-мод (MC 26.2, Java 25+), который рисует косметику на голове игрока, когда
слот шлема пуст. Всё содержимое задаётся **ресурспаком**, мод сам ничего не хранит.

Поддерживается два типа косметики:

- **item** — обычная ванильная JSON-моделька (Blockbench, `elements`),
- **geckolib** — анимированная геометрия (`.geo.json` + `.animation.json`, мягкая зависимость).

GeckoLib — мягкая зависимость: если его нет, работают item-косметики, а geckolib-записи пропускаются.

## Установка

1. Собери: `./gradlew build` → jar в `build/libs/`.
2. Положи `pseudohat-1.0.0.jar` в `mods/`.
3. Положи ресурспак (см. ниже) в `resourcepacks/` и включи его в игре.

## Как это работает

Мод читает из ресурспака два вида файлов в `assets/<ns>/`:

- `config/*.json` — **кто носит**: никнейм → id косметики;
- `config/models/*.json` — **как рисуется**: настройки рендера для каждого id косметики.

Дальше всё зависит от типа: item-косметика рисуется как ванильная модель в `models/item/*.json`,
geckolib-косметика — геометрия из `geckolib/models/*.geo.json` + анимации из
`geckolib/animations/*.animation.json`, привязанная к костям геометрии так же, как в GeckoLib.

Имя файла в `config/models/` не важно — важно id внутри `"cosmetics"`: он должен совпадать с id,
на который указывает маппинг в `config/*.json`.

## Формат конфига

`config/<что-угодно>.json`:

```json
{
  "hats": {
    "PseudohatDev": "pseudohat:hat",
    "AuroraBreeze": "pseudohat:huina"
  }
}
```

`config/models/<что-угодно>.json`:

```json
{
  "cosmetics": {
    "pseudohat:hat": {
      "type": "geckolib",
      "geo": "pseudohat:hat",
      "texture": "pseudohat:textures/entity/hat.png",
      "animations": "pseudohat:hat",
      "scale": 1.0,
      "offset": [0, 0, 0],
      "rotation": [0, 0, 0],
      "glow": true,
      "transparent": false,
      "default": "animation.hat.idle",
      "events": {
        "onSprint": "animation.hat.run",
        "onHurt": { "animation": "animation.hat.hurt", "mode": "once" }
      }
    }
  }
}
```

Поля:

| поле | для типа | что делает |
| --- | --- | --- |
| `type` | оба | `"item"` (по умолчанию) или `"geckolib"` |
| `model` | item | id item-модели (по умолчанию = id косметики) |
| `geo` | geckolib | id геометрии (по умолчанию = id косметики) |
| `texture` | geckolib | текстура (по умолчанию `ns:textures/entity/<geo>.png`) |
| `animations` | geckolib | id файла анимаций (по умолчанию = geo) |
| `scale` | оба | множитель размера (по умолчанию 1) |
| `offset` | оба | сдвиг в пикселях геометрии (16 на блок, y вверх) |
| `rotation` | оба | поворот в градусах |
| `glow` | оба | `true` / `false` / объект — см. «Свечение» |
| `transparent` | geckolib | `true` — полупрозрачное смешивание вместо cutout (дым, мягкие края) |
| `default` | geckolib | анимация, которая крутится, когда ничего не сработало |
| `events` | geckolib | правила «событие → анимация» |

Никаких настроек головы в конфиге нет: положение задаётся `display.head` в модели, а
`offset`/`rotation`/`scale` — только доводка.

### События

`events` — это правила «триггер → анимация». Правила проверяются по порядку записи, **первое
совпавшее** запускает свою анимацию (порядок = приоритет). Форма записи:

- строка `"onSprint": "animation.hat.run"` — анимация крутится по кругу, пока триггер удерживается;
- объект `"onHurt": { "animation": "animation.hat.hurt", "mode": "once" }` — проигрывается один раз
  при старте триггера, длительность берётся из самой анимации.

Доступные триггеры:

| ключ | срабатывает когда |
| --- | --- |
| `onSneak` | игрок крадётся |
| `onSprint` | игрок бежит |
| `onSwim` | игрок плывёт |
| `onInWater` | игрок в воде |
| `onFallFlying` | игрок планирует на элитрах |
| `onUseItem` | игрок использует предмет |
| `onHurt` | игрок получает урон |
| `onJump` | игрок подпрыгивает/взлетает |
| `onSwing` | игрок машет рукой (атака/взмах) |
| `onWalk` | игрок идёт (движение по земле) |
| `onDeath` | игрок мёртв |

Ключи регистронезависимы и без разницы в разделителях: `onSneak`, `ON_SNEAK` и `on_sneak` — одно
и то же событие. Неизвестный ключ молча пропускается с предупреждением в лог, остальные правила
работают дальше — конфиг, написанный под более новую версию мода, не роняет всю косметику.

`default` крутится, когда ничего не совпало; если нет ни совпадения, ни `default` — модель стоит
в bind-pose.

## Позиционирование

Модель рисуется целиком в голове: авторская точка отсчёта — центр головы (+y вверх). Ванильная
голова — 8 гео-пикселей (0.5 блока), оборачивай её кубами начиная с `y = 4` (верх головы).

Точный размер/поворот, который ты видишь в блокпревью Blockbench, получается из `display.head`
в файле модели (для geckolib — из отдельного экспорта `models/item/<id>.json`:
`{"parent": "builtin/entity", "display": {"head": {...}}}`). Если у геометрической модели есть
такой display-файл — берётся он и `GEO_SCALE` не применяется; иначе рендер использует
стандартную посадку (коэффициент 1.6 для модели в блоках).

## Свечение

`"glow": true` включает второй проход на полной яркости:

- **item**: перерисовывается та же модель — светится всё. Вариант `"glow": {"model": "ns:path"}` —
  рисуется вторая, меньшая модель (эмуляция glowmask: только те части, что есть в ней).
- **geckolib**: если рядом с текстурой лежит `<текстура>_glowmask.png` (белый = светится,
  чёрный = нет, цвет берётся из базовой текстуры) — `AutoGlowingGeoLayer`; если нет — базовая
  текстура рисуется целиком на полной яркости. Вариант
  `"glow": {"texture": "ns:..."}` — отдельная эмиссивная текстура, рисуется как глаза (в полной
  яркости, «развёртка в реальных цветах», не ч/б).

## Прозрачность

По умолчанию GeckoLib рисует базовую модель через `entityCutout` — это alpha-test без блендинга,
поэтому полупрозрачные пиксели (дым, мягкие края) выглядят непрозрачными. Для таких моделей
добавь `"transparent": true` — включится `entityTranslucent` с честным альфа-смешиванием.

## Структура ресурспака

```
<pack>/
├── pack.mcmeta                          # обязателен (pack_format 88)
└── assets/
    └── pseudohat/
        ├── config/
        │   ├── hats.json                # ник → id косметики
        │   └── models/
        │       └── hat.json             # настройки рендера (id внутри = id косметики)
        ├── geckolib/
        │   ├── models/hat.geo.json      # геометрия (для geckolib)
        │   └── animations/hat.animation.json
        ├── items/hat.json               # item-обёртка (только для item-косметик)
        ├── models/item/hat.json         # item-модель / display для geckolib
        └── textures/
            ├── block/*.png              # текстуры item/geckolib
            └── entity/*.png             # текстуры по умолчанию + *_glowmask.png
```

## Ограничения

- Мод клиентский: косметику видит только сам игрок (сервер не синхронизирует).
- Пишется в ресурспак с namespace `pseudohat`, но конфиги `config/models` могут быть в любом
  namespace — id просто должен совпадать с маппингом.
- `items/` нужны только ванильным item-моделям; geckolib их не читает.

## Разработка

```sh
./gradlew build                              # сборка + тесты
./gradlew test                               # юнит-тесты парсера и sample-пака
./gradlew runClient --args="--quickPlaySingleplayer TEST"
```

Sample-пак лежит в `run/resourcepacks/pseudohat-sample/`; логика описана в `AGENTS.md`.
